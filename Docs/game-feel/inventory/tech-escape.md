## Rules used

- A **word** is a whitespace-separated token containing at least one letter or digit. `·`, `/`, `+`, `▲`, `▼` alone are not words; `1.1`, `08`, `23:47:04`, `(443)`, `allow-all`, `"So` are. Counts are computed by script from the transcriptions below.
- **Total** = every UI word visible in the frame, including text dimmed behind an overlay and the logo wordmark (title only, counted as 1). **3D world signage** (door signs inside the rendered facility) is listed per screen but **not** in the total.
- Text below the drawer's fold is counted separately ("below the fold") because it is not visible without scrolling.
- **CUT** = clipped by a panel edge, a scroll viewport, or (attack early) still typing.
- Path played: the student **fixes** the room, then runs the attack (main rows). Rows marked [variant] are the same level with RUN THE ATTACK pressed on the room as handed over.
- Frames were frozen for capture with `unityInstance.Module.pauseMainLoop()` (my copy of the play tool, `play-te.mjs`: steps `pause`/`resume`/`drag`/`wheel` added) because the machine was loaded and a plain screenshot took up to 27 s, long enough for LUMA's fading lines to disappear.

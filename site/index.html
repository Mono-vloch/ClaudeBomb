How it works

One code, every game. Your instructor gives the class a code. It opens this menu, and every game on it, for the day.

Claude is on the inside. The games that talk to Claude do so through the academy, so you never need a key or an account.

Short on purpose. A game is fifteen to twenty minutes: long enough to learn the one idea it is built around, short enough to fit in a class.
